# Legacy

Archived reference frontends and the Clinical Execution Explorer.

**Active product UI** lives in [`waggy-frontend/`](../waggy-frontend/). FastAPI `GET /` and `GET /demo` serve that workbench. `GET /classic`, `GET /business`, and `GET /developer` are aliases of the same page.

This folder is **not** a second product frontend.

- `archive/frontend/` — classic customer, standalone business, and PPIE phone-shell files (reference only)
- `debug/calculation.html` — Clinical Execution Explorer (internal debug)
- `ppie-validation-console.js|css` — explorer assets

See [docs/WAGGY_SYSTEM.md](../docs/WAGGY_SYSTEM.md), [docs/frontend-consolidation-inventory.md](../docs/frontend-consolidation-inventory.md), and [docs/omega17.4-fe-completion-report.md](../docs/omega17.4-fe-completion-report.md).
