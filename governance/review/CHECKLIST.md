# Scientific Review Checklist

For every proposed science change:

- [ ] Author identified (`created_by` / `modified_by`)
- [ ] Change reason recorded
- [ ] Supporting paper DOI / paper_id present
- [ ] Affected formulas listed (impact analysis)
- [ ] Affected breeds / conditions listed
- [ ] Extended validation PASS (`governance/validation/SCIENCE_VALIDATION_REPORT.md`)
- [ ] Parity suite PASS (clinical outputs identical)
- [ ] Benchmark report attached
- [ ] Rollback path: previous `warehouse/releases/<version>/`
- [ ] Reviewer sign-off

Statuses: `draft` → `validation` → `scientific_review` → `approved` → `published` → `production`
