# PRESENTATION_ARCHITECTURE

## Runtime truth (Ω9.6F)

Current production/demo runtime owner remains `app/`:

`frontend/static -> local gateway -> app.main / app.api.main -> app.agent.engine.PPIEWellnessAgent -> existing Wagtopia runtime`

Repository v2 architecture remains parallel/test-focused and is not claimed as production runtime owner in this phase.

## Layered presentation stack

### Presentation Layer

- Customer Browser UI (`legacy/index.html`, `legacy/app.js`, `legacy/ppie-shell.js`)
- Developer Calculation Explorer (`legacy/debug/calculation.html`, `legacy/ppie-validation-console.js`)
- Native CSTC Desktop Shell (`app/ui/cstc/*`)

### Presentation Adapter Layer

- `app.ui.cstc.adapter.WagtopiaPresentationAdapter`
- `app.ui.cstc.models.AnalysisPresentation`
- `app.ui.cstc.view_models.build_presentation`

Responsibilities:

- translate UI request/response shapes
- normalize existing runtime payloads for presentation
- avoid scientific calculations

### Transport

- HTTP API contracts in `app/api/main.py`
- local gateway proxy in `scripts/run_wagtopia_local.py`
- customer-only remote gateway in `scripts/run_wagtopia_remote.py`

### Application Runtime

- `app.api.main`
- `app.agent.engine.PPIEWellnessAgent`

### Scientific / Recommendation Runtime

- Existing Ω1-Ω9.x app runtime modules used by `PPIEWellnessAgent`
- Repository runtime remains non-cutover in this phase

## Interface boundaries

- Customer UI and CSTC desktop consume API outputs only.
- Developer UI consumes debug contracts only (`/api/v1/ppie/*`) and remains local-facing.
- Remote tunnel in Ω9.6F exposes only customer surface through gateway `:8080`; API `:8000` remains local.

## Ω9.6G provenance boundary

Developer execution cards are read-only provenance projections and must keep these concerns independent:

- Execution
- Formula documentation
- Replay capability
- Scientific support
- Publication readiness

Customer presentation remains concise and does not expose internal formula/debug internals.

## Deterministic demo profile

- Canonical profile: `mixed_lab_golden` (`Dolly`).
- Customer UI provides a visible `Load Demo Dog` control.
- Scientific outputs are still generated by existing runtime; presentation does not fabricate data.
